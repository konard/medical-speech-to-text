## Release gates

No clinical release until the issue 1 residency, consent, locked clinical test,
critical medical-error, correction-time, p95 latency and confirmation gates pass.
No Rust path was added: there is no new port, carried behavior or unsupported
translation represented as complete. Every new native browser adapter is recorded
in [verification](verification.md). A future port must satisfy the strict readiness
and regenerate/parity gates in `docs/javascript-first.md` before any Rust CI.
