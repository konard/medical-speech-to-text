# Engine and industry workflow comparison

Reviewed **2026-10-30** using [primary documentation](sources.md). This is a curated
comparison of **20 solution families**, covering established cloud services and
widely used open deployment stacks, with newer candidates called out. Numbering
is for reference, not a market-share ranking. Vendor case studies, availability of
maintained SDKs/production deployment documentation, and public model/tool use are
maturity signals, not independent proof of clinical accuracy or the “20 largest”
vendors. No comparable audited global popularity dataset was found. Model release,
region, feature, account and contract must be checked together before procurement.

## Clinical scribe products and practices

Engine rankings miss the workflow that determines whether a clinical system is
usable. Compare a buy-vs-build pilot against [Microsoft Dragon Copilot](https://www.microsoft.com/en-us/health-solutions/clinical-workflow/dragon-copilot),
[Heidi](https://www.heidihealth.com/), [Abridge](https://www.abridge.com/),
[Nabla](https://www.nabla.com/security), [Suki](https://www.suki.ai/) and
[Augmedix](https://www.augmedix.com/). These are clinical documentation products,
not six interchangeable raw ASR endpoints or proof of Australian AWS eligibility.

Use their workflow patterns as evaluation questions: consent visibility,
source-linked notes, customizable templates, terminology, specialist workflows,
EHR context, clinician sign-off, auditability and correction effort. Product
marketing and compliance certifications do not replace region/subprocessor checks.
For example, Nabla's trust page describes US/EU storage and separate backups;
M365 Copilot residency promises must not be applied to Dragon Copilot without
product-specific evidence. Obtain a written map of raw speech, ASR, note generation,
telemetry, backups and support before involving private clinical data.

## Shortlist and selection method

1. Eliminate candidates failing AU processing/storage, licensing, required language,
   security or timestamp/streaming contracts. Unknown eligibility is a failed gate
   for real patient data, not an assumed pass.
2. On public data compare browser Whisper, AWS standard/Medical Sydney,
   self-hosted Whisper, Parakeet and a true streaming NeMo checkpoint. Add Deepgram
   AU and Speechmatics AU/private if their exact account/contract is eligible.
3. On consented locked clinical data rank safety errors first, then clinician
   correction time and WER, p95 delay, subgroup gaps, cost and operational effort.
   Publish the Pareto frontier rather than one opaque composite score.
4. Recheck current model releases and region tables each quarter and before every
   procurement/production upgrade. Keep the previous model available for rollback.
